# Fingerdot installers

This repository holds only the installers of the Fingerdot desktop agent (formerly called TraceMark). Download them from the [Releases](../../releases) page or from https://web-production-800bb4f7.up.railway.app/#download.

The Windows installers are not code-signed yet, so Windows may show "Windows protected your PC". Click "More info", then "Run anyway".

Version 0.1.0 was published under the old name TraceMark Agent. Version 0.2.0 and later are Fingerdot; on first start, 0.2.0 removes the 0.1.0 start-at-login entry and the right-click entry so the two do not run side by side.
